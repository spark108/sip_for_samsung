# SIP для Samsung

Android-приложение добавляющее поддержку SIP-учётной записью для стандартного приложения «Телефон».

## Установка и настройка

1. Установите приложение SIP скачав последний релиз с данного репозитория.
2. Откройте установленное приложение **SIP**.
3. Откройте **Учётную запись SIP**. Введите логин, домен, пароль и при необходимости адрес прокси SIP. Для TLS используйте, например, `sip:pbx.example.org:5061;transport=tls` (провайдер должен поддерживать TLS).
4. Включите переключатель **SIP-вызовы** и разрешите доступ к микрофону.
5. Откройте **Учётные записи для вызовов** и включите SIP-аккаунт. На Samsung он может быть первоначально отключён.
6. В приложении **Телефон** выберите SIP-аккаунт при исходящем вызове, если интерфейс предлагает выбор.

Для приёма входящих вызовов SIP должен быть включён. После перезагрузки телефона включите его в приложении снова.

## Сборка

Требуются Android SDK (API 36), JDK 17+ и интернет для зависимости Linphone SDK. В PowerShell:

```powershell
$env:ANDROID_HOME = 'C:\Users\Spark108\AppData\Local\Android\Sdk'
$env:JAVA_HOME = 'C:\Program Files\BellSoft\LibericaJDK-21-Full'
$env:GRADLE_USER_HOME = "$PWD\.gradle-user"
.\gradlew.bat :app:assembleDebug
adb install -r .\app\build\outputs\apk\debug\app-debug.apk
```

`GRADLE_USER_HOME` указан отдельно, так как глобальный `~/.gradle/init.gradle` на этом компьютере перенаправляет все репозитории в локальный Nexus и не содержит Android Gradle Plugin.

## Обновления и выпуск

Экран **О программе** проверяет последний стабильный [GitHub Release](https://github.com/spark108/sip_for_samsung/releases). Android просит подтвердить установку. Разрешение на установку можно выдать в разделе **Дополнительно → Разрешения → Установка обновлений**.

Для выпуска увеличьте `versionCode` и укажите `versionName` в `app/build.gradle`. Соберите `:app:assembleRelease`, подпишите APK через `apksigner` тем же ключом, которым подписан предыдущий выпуск, и приложите файл `SIP.apk` к стабильному релизу с тегом `v<versionName>`. Приложение сверяет SHA-256 из метаданных GitHub, имя пакета, версию и сертификат подписи. Храните ключ подписи отдельно от репозитория.

## Ограничения

- Поддерживается одна SIP-учётная запись, аудиозвонки, ответ, завершение, удержание и DTMF. Видео, перевод звонка и SMS не реализованы.
- В разделе **Уведомления SIP** открываются системные настройки видимости. Android требует foreground-уведомление во время работы SIP-сервиса; оно может быть скрыто из шторки настройками Android, но системный индикатор активного сервиса остаётся под контролем ОС.
- Пароль хранится в Android Keystore, не экспортируется при резервном копировании. Сервис поддерживает SIP-прокси, указанный в форме. Без `transport=tls` сигнализация может идти без TLS; медиа-шифрование зависит от провайдера и его настроек.
